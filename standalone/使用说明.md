# 纯前端版使用说明

这个文件夹是一个**不需要服务器**的完整答题网页：把整个 `standalone`
目录拷给别人（或上传到静态托管），打开 `index.html` 就能玩。

## 三种拿到它的方式

- **在线玩**：https://lixmo17.github.io/mysweb/ （推送到仓库后自动更新）
- **要压缩包**：直接用同目录下的 `题库测试1.zip`，解压就能用，适合直接发给别人
- **要源码**：`index.html` 加 `questions/` 图片文件夹

## 直接使用

- **双击打开**：双击 `index.html`（推荐 Edge / Chrome）。
- **本地起服务**：在 `standalone` 目录执行 `npx serve .`，然后访问提示的地址。
- **传到网上**：把 `standalone` 目录里的内容上传到任意静态托管
  （Vercel / Netlify / GitHub Pages / 对象存储 / 校园服务器都行），
  首页是 `index.html`。十几台设备同时访问没有压力。

目录里需要一起带着的东西：

```
standalone/
├─ index.html      ← 网页本体（含题库）
└─ questions/      ← 题目配图
```

## 玩法

1. 首页点「开始游戏」，系统从题库随机抽 10 道题。
   题库共 73 题（普通 48 题 + gal 25 题），gal 题出现得比普通题少，
   平均每次大约 9 道普通题、1 道 gal 题。
2. 选择题点选项后立刻判对错：选错标红、正确答案标绿；答完自动累计到正确率。
3. 现场题（填空题）只展示题目和配图，答案由现场工作人员口头判定，
   不计分、不计入正确率。
4. 十道题答完点「提交答卷」看结果。
5. 首页下方小按钮「查看题目正确率」可以看每道题的正确率。

## 多台设备怎么汇总数据

每台设备的统计存在**它自己的浏览器**里，互不相通。活动现场这样汇总：

1. 在某台设备上打开「查看题目正确率」，点「生成成绩码」，把这段文字
   （`MW1-` 开头）发给负责汇总的同学（微信 / QQ 发文字即可）。
2. 汇总的电脑上，把成绩码粘贴到页面下方「把别人给的成绩码粘贴到这里」，
   点「合并成绩码」，各台设备的数据就会相加。
3. 同一份成绩码重复粘贴会被自动忽略，不会重复计数。
4. 汇总完点「导出正确率报表」，会下载一个 `正确率统计.txt`，
   用 Excel 直接打开就是表格。

> 小提示：成绩码是纯文本，长度几百字符，可以正常用聊天软件传输。
> 汇总机自己也答过题的话，记得把它自己的数据算进去（它本机的数据本来就在）。

## 改题库

用记事本或 VS Code 打开 `index.html`，找到这一行：

```
<script id="question-bank" type="application/json">
```

它下面那段 JSON 就是题库，格式和 `../data/questions.json` 完全一样，
加完题保存刷新即可，不用重新打包。

## 常见问题

**能被看到答案吗？**
能。纯前端版本把题库和答案一起发给浏览器，按 F12 可以看到。
如果介意这一点，就用 `mysweb` 根目录的服务端版本，答案存在服务器上。

**统计数据会丢吗？**
统计存在浏览器本地存储里。清理浏览器数据、换浏览器、用无痕模式都会丢，
所以活动结束建议尽早生成成绩码或导出报表留档。

**换了台电脑打开，之前的数据还在吗？**
不在。数据跟着浏览器走，不跟着文件走。
